## 알려진 경계

GitHub Release API 기준 `v0.1.0`의 `immutable` 값은 `false`다. GitHub 공식 정책상 repository의
release immutability를 활성화해도 이후에 발행하는 release부터 적용되므로 이 릴리스를
immutable로 소급 표시하지 않는다.

image digest와 Sigstore attestation은 검증됐지만 GitHub Release 자체의 tag·asset lock은 없다.
repository release immutability는 2026-08-30 활성화했지만 기존 release에는 소급되지 않는다.
차기 release부터 draft에 모든 asset을 준비한 뒤 publish하고 `immutable: true`를 검증한다.
